### AI Invoice Automation System

An AI-powered invoice processing and expense management application built using Python, FastAPI, OCR and Google Gemini API.

Key Features

- Upload invoices in PDF, PNG and JPG formats.
- Automatically extract invoice details using OCR and AI.
- Google Gemini API integration for intelligent data extraction.
- Regex-based fallback when AI extraction is unavailable.
- Review and approve extracted invoice information.
- Store invoice records using SQLite.
- Search and filter invoice records.
- Expense analytics dashboard with monthly visualizations.
- Export invoice records as CSV.

Tech Stack

Python | FastAPI | Google Gemini API | Tesseract OCR | PyMuPDF | SQLAlchemy | SQLite | HTML | CSS | JavaScript | Chart.js

What I learned

- Building REST APIs using FastAPI.
- Integrating LLM APIs into real-world applications.
- Processing PDF and image-based documents.
- Implementing OCR and fallback extraction.
- Database management using SQLAlchemy and SQLite.
- Developing interactive dashboards and data visualizations.
